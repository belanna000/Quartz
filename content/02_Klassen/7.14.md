# 7.14

## Schülerliste
```base
filters:
  and:
    - file.hasTag("schueler")
    - note.klasse == this
views:
  - type: table
    name: Schüler
    order:
      - nachname
      - vorname
      - besonderheiten
      - eltern_email
    sort:
      - property: status
        direction: ASC
      - property: nachname
        direction: ASC
  - type: table
    name: Mit Bemerkungen
    filters:
      and:
        - note.besonderheiten == true
    order:
      - nachname
      - vorname
      - sitzplatz_hinweis
      - foerderbedarf
  - type: table
    name: Förderbedarf
    filters:
      and:
        - note.foerderbedarf != ""
    order:
      - foerderbedarf
      - nachname
      - vorname
  - type: table
    name: View
    sort:
      - property: file.name
        direction: ASC

```

## Checklisten

Konsolidierte Übersicht aller Haken aus den Checklisten in 06_Checklisten – hier direkt anklickbar. Details/Hintergrund zu einzelnen Einträgen: [[06_Checklisten/Erste Elternversammlung]], [[06_Checklisten/Pflichtformulare Schuljahresbeginn - 7.14]].
```base
filters:
  and:
    - file.hasTag("schueler")
    - note.klasse == this
properties:
  ev1_anwesend:
    displayName: Elternversammlung
  pf_schulverfassung_e:
    displayName: Schulverf. (E)
  pf_schulverfassung_s:
    displayName: Schulverf. (S)
  pf_foto_e:
    displayName: Foto (E)
  pf_foto_s:
    displayName: Foto (S)
  pf_sporthalle_e:
    displayName: Sporthalle (E)
  pf_sporthalle_s:
    displayName: Sporthalle (S)
  pf_ausweis_e:
    displayName: Ausweis (E)
  pf_ausweis_s:
    displayName: Ausweis (S)
  pf_o365_e:
    displayName: O365 (E)
  pf_o365_s:
    displayName: O365 (S)
  pf_fehlzeiten_e:
    displayName: Fehlzeiten (E)
views:
  - type: table
    name: Alle Haken
    order:
      - nachname
      - vorname
      - ev1_anwesend
      - pf_schulverfassung_e
      - pf_schulverfassung_s
      - pf_foto_e
      - pf_foto_s
      - pf_sporthalle_e
      - pf_sporthalle_s
      - pf_ausweis_e
      - pf_ausweis_s
      - pf_o365_e
      - pf_o365_s
      - pf_fehlzeiten_e
    sort:
      - property: nachname
        direction: ASC
  - type: table
    name: Offene Pflichtformulare
    filters:
      and:
        - "!(pf_schulverfassung_e && pf_foto_e && pf_sporthalle_e && pf_ausweis_e && pf_o365_e && pf_fehlzeiten_e)"
    order:
      - nachname
      - vorname
      - pf_schulverfassung_e
      - pf_foto_e
      - pf_sporthalle_e
      - pf_ausweis_e
      - pf_o365_e
      - pf_fehlzeiten_e
    sort:
      - property: nachname
        direction: ASC
```
